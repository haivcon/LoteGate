第一次使用？如何获取访问密钥

本机运营者：在启动服务的同一个 PowerShell 窗口中，用下列命令查看已设置的密钥。远程访问者请向部署管理员获取密钥，不要使用明文公网 HTTP。

$env:LOTEGATE_TOKEN

如果服务尚未启动，在项目目录的同一个 PowerShell 窗口依次执行：

$env:LOTEGATE_TOKEN = node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
$env:LOTEGATE_TOKEN
npm start

01 / 准备订单

创建交易批次

第一次使用？示例包含一笔买单和一笔卖单，不会自动保存或执行。

100 基点 = 1%，最高 1000 基点 = 10%。手续费从每笔卖单成交金额中扣除并向下取整。当前费率：0%。

先统一单位，再输入数字

例如数量单位为“箱”、报价单位为“元/箱”。本版本不保存单位字段，请在外部协议中记录，必要时在批次名称中注明。价格和数量为 1–4,294,967,295 的整数，最多 64 笔订单。

买入填写最高可接受价格；卖出填写最低可接受价格（扣费前）。
订单编号买入 / 卖出限价数量操作
成交价格和优先顺序如何确定？

买单按限价从高到低，卖单从低到高匹配；同价订单按录入顺序优先。统一成交价为最后一笔已成交卖单的限价。订单编号必须唯一，单一卖方模式最多录入一笔卖单。
